## Similarity Based Chunking deduplication
- Delta encoding algorithms (Xdelta, Zdelta, Edelta, Ddelta) have been implemented
- A comparison has been made with Content Defined Chunking.

**Source code:** https://github.com/maxscherbakov/sbc_algorithm

**Actual fork:** https://github.com/admitrievtsev/marline

## NFS Mamont
- The synchronous procedures of the NLM protocol (Lock, Unlock, Test, Cancel) have been implemented.
- Currently, the callback mechanism for the granted procedure is under active development.

**Source code:** https://github.com/RMamonts/nfs-mamont

**Example of how to use nfs-mamont:** https://github.com/RMamonts/mirror-fs
